    How it works

    The files are built into this page itself. Nothing is downloaded, uploaded or sent anywhere: opening a file here only reads the copy that arrived with the page.

    The Text view shows a file’s bytes the way a plain text viewer would. Bytes that aren’t text show as dots or odd characters, dimmed; point at one (or hold a finger on it) to see its value.

    The Bytes view shows the value of every byte in the file, in hexadecimal, sixteen to a row (eight on a narrow screen), with each row’s offset from the start of the file. The column on the right repeats the bytes as letters where they are plain letters, digits or punctuation, and as dots where they aren’t.

    The other views read a file the way an ordinary program would. If a file can’t be read that way, the view says why, and the Text and Bytes views still show everything in it.

    The page remembers which file and view you had open, in this browser only. The address in the address bar also changes as you go, so you can bookmark or share a view.
