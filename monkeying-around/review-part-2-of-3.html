An optional helper: a workbench for the Vigenère family of ciphers, for when you know a key or want to try one, with a chain of simple steps for doing more to the result. It doesn’t guess keys, find key lengths or try to break anything. It runs entirely in your browser and keeps working once it has loaded, even with no signal. What you type stays on this device.

The cipher

A keyed alphabet is the keyword’s letters, each used once, then the rest of A to Z in order. Sources differ on where the key letter (the indicator) lines up: left blank, it goes under the first letter of the plaintext alphabet, as in the Kryptos tableau; type a letter, such as A, to put it under that plaintext letter instead.

When the key runs out

Trithemius has no key: each letter is shifted by the starting shift plus the step times its position, so the shifts go 0, 1, 2, 3 … with the usual settings. Set them under The cipher.

What counts as a letter

Spaces, digits, punctuation, and letters outside A to Z
Folding: read these as plain A to Z, in the message and in the key

Folded letters come out as plain letters, in the message’s own case. Letters from other scripts, such as Greek or Cyrillic, are always left in place and never move the key on. A letter that isn’t folded (é with accents off, say) counts with the spaces and punctuation above.

      About the ciphers

      Letters are numbers here: A = 0, B = 1, … Z = 25, and every sum is taken mod 26, so it wraps round from Z back to A. P is a plaintext letter, C its ciphertext letter and K the key letter used on it.

      CipherEncipherDecipher
      VigenèreC = P + KP = C − K
      BeaufortC = K − PP = K − C
      Variant BeaufortC = P − KP = C + K
      GronsfeldC = P + dP = C − d
      TrithemiusC = P + s + i·tP = C − s − i·t

      Vigenère adds the key letter, so a key of A changes nothing and a key of B shifts one place. Beaufort subtracts the message letter from the key letter; because K − (K − P) = P, enciphering and deciphering are the same thing. Variant Beaufort subtracts the key, so it enciphers exactly the way Vigenère deciphers. Gronsfeld is Vigenère with a key of digits d from 0 to 9; only the key’s digits are used.

      Autokey here is the plaintext autokey: the key you type is the primer, and once its letters are used up, the message’s own plaintext letters follow it as the key. With a primer of QUEENLY, ATTACKATDAWN is keyed by QUEENLYATTAC. Choose whether its letters are combined by the Vigenère, Beaufort or variant Beaufort rule. Because the key comes from the message’s letters, spaces and punctuation never move it on in autokey.

      Porta has 13 alphabets, one for each pair of key letters (A or B, C or D, … Y or Z). In each one, the first half of the alphabet (A to M) swaps with the second (N to Z): with the pair numbered r (A B is 0, C D is 1, … Y Z is 12), a letter P from A to M becomes 13 + (P + r) mod 13, and the swap undoes itself, so the same key deciphers. This is the Porta table most modern references use; some older books lay it out differently, so check that yours matches the one below.

      Trithemius uses no key: letter number i (counting from 0) is shifted by the starting shift s plus i times the step t. The classic form, with s = 0 and t = 1, leaves the first letter alone, shifts the second by one, the third by two, and so on.

      Quagmires use keyed alphabets. Write the plaintext alphabet along the top; under it, slide the ciphertext alphabet along until the key letter sits under the chosen plaintext letter (the indicator position); then read each message letter’s ciphertext letter straight below it. As a formula, with places counted from 0: the slide s is the key letter’s place in the ciphertext alphabet CA minus the indicator’s place in the plaintext alphabet PA, and C = CA[pos(P) + s], where pos(P) is the place of P in PA; deciphering runs it backwards, P = PA[pos(C) − s] with pos(C) the place of C in CA. Quagmire I keys only the plaintext alphabet, II only the ciphertext alphabet, III uses the same keyed alphabet for both, and IV two different ones. With no keywords, every Quagmire is plain Vigenère. The first two sections of the Kryptos sculpture’s ciphertext are Quagmire III, keyed with KRYPTOS, with the key letter under the first letter of the plaintext alphabet.

      Keys. The key’s letters are read with the same folding as the message, and anything else in the key (spaces, punctuation, other scripts) is skipped. A short key repeats; a running key, such as a passage from a book, is used once from where it starts, and the page says so plainly when it’s shorter than the message, showing _ for each letter it didn’t reach. Starting at a later letter is how you’d use, say, a passage that begins partway down a page.

      Monkey business. The steps are exact, and none of them repairs anything: a number, code or Morse group that can’t be read shows as ? and is listed, and a setting that doesn’t make sense stops the chain at that step until it’s fixed. A1Z26 numbers the letters A = 1 to Z = 26. Character codes are Unicode code points, the same as ASCII for plain letters, digits and punctuation. Morse is the international code, plus !. Writing in rows and reading down the columns, then writing down the columns and reading along the rows at the same width, gives back the text you started with; when the block isn’t full, its left-hand columns are the longer ones.

      What it doesn’t do. It doesn’t guess keys, find key lengths or attempt any other cryptanalysis. Its Caesar shifts come in order from 1 to 25 and its letter counts are information only: nothing on the page ranks results or says which one reads like words. It’s a workbench for when you know a key, or are trying one.
