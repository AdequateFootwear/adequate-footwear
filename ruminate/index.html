    How it works

    Every reader on this page was written for it, and it all runs on your device. Nothing you give it leaves this browser: there is no upload, no server and no tracking. The only thing it remembers between visits is a setting or two, such as whether long lines wrap.

    The views a file gets are chosen by the end of its name, the way a computer’s file manager does it. Open as… lets you read any file any other way. If a file can’t be read the way you asked, perhaps because it is damaged or isn’t that kind of file, the view says why instead of guessing; nothing is repaired or filled in.

    The Structure view labels how a format lays out its bytes: headers, blocks, pages, tags, and the space between them, each with its offset and length. Every byte of the file belongs to some item, and choosing an item marks its bytes in the Bytes view.

    The Listen and Watch views play sound and video files in this browser, with its own player, right here in the page; nothing plays until you press play. The page doesn’t decode or analyse the sound or the picture itself, so which files play depends on the browser, and one it can’t play gets a note saying so.

    The Text view shows the bytes the way a plain text viewer would, and the Bytes view shows the value of every byte, in hexadecimal, with each row’s offset. Those two always work, whatever the file.
